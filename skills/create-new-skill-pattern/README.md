# Create New Skill Pattern

Meta-skill for creating, updating, or auditing opencode skills. Provides template structure, criticality assessment (STRICT vs FLEKSIBEL), enforcement patterns, anti-patterns, and self-update mechanism.

**Loaded:** Manually when creating a new skill, updating an existing skill, or auditing skill quality.

**Produces:** New SKILL.md files following the standard template, criticality assessments, self-enforcement sections, and checklist validation.

**Changes:** README.md standard rule added — WAJIB for skills >500 lines or complex workflows.
