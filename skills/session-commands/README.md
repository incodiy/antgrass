# Session Commands

Quick reference guide for OpenCode session management commands. Covers `/clear` (clear context), `/compact` (compress session), `/new` (start fresh), `/resume` (continue previous), `/fork` (branch session), and `/rename` (label session).

**Loaded:** Manually — pull this skill when you need a reminder of session management slash commands and their usage.

**Produces:** Reference documentation only. Does not produce artifacts — serves as a cheat sheet for interactive session management.
